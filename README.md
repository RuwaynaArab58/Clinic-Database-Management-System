Clinic Database Management System

Project Overview

The Clinic Database Management System is a university project developed to organize and manage clinic information using a relational database. The system focuses on storing and managing information about patients, doctors, appointments, and medical records.

The main goal of this project is to provide a structured way to organize clinic data and make information easier to access and manage.

Project Objectives

- Organize patient and doctor information.
- Manage appointments between patients and doctors.
- Store medical records, including diagnoses and treatments.
- Maintain data accuracy and consistency.
- Retrieve useful information using SQL queries.

Database Entities

The database includes the following main entities:

1. Patient

Stores patient information, such as:

- Patient ID
- Name
- Gender
- Age
- Phone Number

2. Doctor

Stores doctor information, such as:

- Doctor ID
- Name
- Specialty
- Phone Number

3. Appointment

Stores appointment information, including:

- Appointment ID
- Appointment Date
- Appointment Time
- Patient ID
- Doctor ID

4. Medical Record

Stores medical information, including:

- Record ID
- Diagnosis
- Treatment
- Patient ID
- Doctor ID
